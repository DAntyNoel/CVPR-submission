# Convergence Audit

This directory records whether the V3 conclusion is proven, contradicted, or
still under-supported.

The final audit must be evidence-based. Do not mark the task complete only
because result files exist.

Required final checks:

1. current V3 evidence snapshot exists;
2. paper-facing no-compute review gaps are closed or explicitly waived;
3. seed stability either supports the central claim or the paper claim is
   weakened accordingly;
4. relation-stress results support the relation-bottleneck statement or the
   paper is updated;
5. optional backbone transfer is either completed or explicitly deferred with
   justification.
