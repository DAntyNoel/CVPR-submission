# Relation-Stress Results

This directory stores the locked relation-only probe and its evaluation
results.

Expected files:

```text
relation_stress_probe.jsonl
relation_stress_probe.summary.json
metrics.csv
job_manifest.md
qualitative_cases.md
```

The probe is generated by `scripts/eval/prepare_relation_stress_probe.py` from
the held-out GQA simple relation rows. It should not be used for training or
adapter selection.
