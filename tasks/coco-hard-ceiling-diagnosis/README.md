# COCO Hard Ceiling Diagnosis

Created: 2026-05-27

Last checked: 2026-05-27 13:47:51 CST (+0800)

## Executive Decision

COCO object-existence should be treated as a ceiling-limited sanity check for
this toy CVPR submission, not as the main source of evidence. The normal
held-out split and the current Hard COCO split are both balanced and
leakage-free, but Qwen2.5-VL-7B-Instruct is already above 94% accuracy on both.

The main paper should therefore make its primary claim from the mixed
COCO/GQA comparison, especially GQA simple and false-positive behavior, while
using COCO to show that the method does not break common object recognition.
Hard COCO can be reported as a short diagnostic table or appendix row if the
final mixed Evidence-Hint DPO result is available before writing freeze.

No additional training method or fourth main experiment group is recommended.

## Hard COCO Construction

Hard COCO is generated by `scripts/eval/prepare_coco_hard_eval.py` from COCO
train2017 annotations and the held-out image id list:

```bash
python scripts/eval/prepare_coco_hard_eval.py \
  --heldout-image-ids data/eval/heldout_object_existence_image_ids.txt \
  --output data/eval/coco_hard_object_existence.jsonl \
  --max-pairs 500 \
  --seed 42
```

Key construction facts from
`data/eval/coco_hard_object_existence.summary.json`:

| Field | Value |
| --- | --- |
| Strategy | same-coarse-group absent-object negatives |
| Candidate pairs | 9,882 |
| Selected pairs | 500 |
| Eval records | 1,000 |
| Unique images | 500 |
| Yes/no balance | 500 / 500 |
| Min visible area fraction | 0.01 |
| Train/eval image overlap | 0 |

The split excludes common low-confidence negatives such as `book`,
`cell phone`, `clock`, `fork`, `handbag`, `knife`, `spoon`, and `tie` unless
`--keep-low-confidence-negatives` is explicitly supplied. This improves label
reliability, but also removes some ambiguous small-object cases that would make
COCO more stressful.

Most frequent selected hard pairs include `bench->stop sign`,
`motorcycle->airplane`, `bench->parking meter`, `car->bicycle`, `bus->boat`,
`motorcycle->bus`, `motorcycle->train`, and `car->motorcycle`.

## Diagnosis

The high Base score is expected rather than suspicious.

1. COCO object-existence yes/no questions cover common categories that the base
   model recognizes well.
2. The current hard negatives are same-coarse-group negatives, but many are
   still visually separable in full-image context.
3. Filtering low-confidence negatives increases label quality while removing
   annotation-sensitive small objects.
4. The normal and hard splits are balanced and leakage-free, so the saturation
   is not explained by obvious train/eval overlap.

Hard COCO does make the task harder, but only mildly: Base accuracy drops from
0.959 to 0.944. The main change is negative-side pressure: Base FPR rises from
0.018 to 0.038, while FNR rises from 0.064 to 0.074.

Mixed Answer-DPO improves Hard COCO accuracy by 0.006 over Base. This gain is
mostly recall-side: it fixes seven Base false negatives and introduces one new
negative-side error. Because the absolute difference is small and there are
only 500 positive and 500 negative questions, this should be described as a
small diagnostic improvement rather than a decisive COCO result.

| False negative | 37 | truck 9, sink 5, chair 4, backpack 3, dining table 3, car 3 |

The most repeated Hard COCO false-positive pairs include
`handbag->backpack`, `chair->potted plant`, `bowl->bottle`, `bus->train`,
`car->bicycle`, and `tv->laptop`. The most repeated false-negative pairs
include `bed->toilet`, `sink->toaster`, `car->bicycle`,
`backpack->suitcase`, `truck->train`, `truck->boat`, and `sink->microwave`.

This pattern supports the ceiling diagnosis: the remaining errors are a small
mix of fine-grained object confusion, context co-occurrence, and hard positives,
not broad hallucination failure.

## Paper Treatment

Use this wording direction in `paper/main.tex`:

- State that COCO object-existence is near ceiling for the base model.
- Treat normal COCO and Hard COCO as controlled sanity checks.
- Avoid claiming that small COCO accuracy differences alone prove the method.
- Emphasize GQA simple and false-positive behavior for the main evidence.
- If final mixed Evidence-Hint DPO improves Hard COCO, report it as a targeted
  diagnostic; if it is flat, keep it in appendix or omit it from the main table.

Suggested concise claim:

```text
COCO object-existence is close to saturated for the base VLM, so we use it
primarily as a sanity check and interpret sub-point differences cautiously. The
harder same-coarse negative split lowers Base accuracy from 95.9% to 94.4%,
confirming mild additional difficulty but not enough headroom for a decisive
standalone conclusion.
```

## Decision Rules

| Outcome after mixed Evidence-Hint DPO eval | Action |
| --- | --- |
| COCO remains near saturated and GQA improves | Main claim should rely on GQA; COCO stays a sanity check. |
| Hard COCO opens a clear false-positive gap | Add Hard COCO as a diagnostic table or appendix table. |
| All COCO variants show tiny differences | Keep COCO out of the core claim and mention ceiling effect. |
| Evidence-Hint helps only on COCO | Narrow the claim to object-existence hallucination. |
| Evidence-Hint does not help | Write the result as a diagnostic/negative finding with ceiling analysis. |

## Optional Stronger Evaluation

Only build another COCO variant if the final narrative still needs a sharper
object-existence diagnostic. Keep it small and do not add a fourth method.

Recommended option: Base-error-mined hard set.

1. Generate a larger held-out candidate pool.
2. Run Base Instruct on the pool through Slurm.
3. Keep only Base-wrong samples after automatic label checks and a small manual
   audit.
4. Evaluate only Base Instruct, Answer-DPO, and Evidence-Hint DPO on the locked
   mined set.
5. Report it as a diagnostic, not as the central benchmark.

Fallback options are fine-grained confusable negatives or a small/occluded
object subset, but both need extra quality checks and are less directly tied to
the observed ceiling.
