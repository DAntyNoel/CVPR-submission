# Generated Improvement Artifacts

This directory is reserved for lightweight generated outputs from the
review-driven improvement pass.

Expected files after the next execution round:

```text
table3_ci.md
slice_ci.md
ablation_results.md
relation_failure_cases.md
```

Do not place large raw generations, adapters, checkpoints, or downloaded
datasets here. Keep those under the existing `results/`, `outputs/`, and
`data/` trees.
