\section{Supplementary Material}

This appendix provides reproducibility details for the controlled COCO/GQA
diagnostic study. It records the data templates, training settings, scoring
rules, and confusion counts used by the full-paper build.

\subsection{Scoring Rules}

All held-out generations are scored with a deterministic yes/no parser. Answers
whose first decisive statement is affirmative are scored as yes; answers whose
first decisive statement is negative are scored as no. Outputs with explicit
uncertainty such as ``cannot determine'' or ``not sure'' are counted as
refusals, while outputs without a parseable yes/no decision are counted as
other/invalid. The same parser is used for Base Instruct, \answerdpo{}, and
\method{}.

Yes bias is the fraction of parsed predictions assigned to yes. The COCO
false-positive rate is computed over negative object-existence questions. GQA
color and left/right errors are computed over their corresponding held-out
slices.

\subsection{Base-Error-Mined Diagnostic Set}

The Base-error-mined set is constructed from errors made by Base Instruct on a
10{,}000-row held-out COCO candidate pool. The locked set contains 527 rows
over 474 images: 123 original Base false positives and 404 original Base false
negatives. It is used only as a diagnostic set for error recovery. On this
pre-audit set, \answerdpo{} recovers 33/527 errors and \method{} recovers
16/527 errors. Both rows have 0.0\% refusal and 0.0\% other/invalid outputs.

\subsection{10k Scale-Up Diagnostic}

The scale-up diagnostic uses separate mixed10k files, adapters, and generation
directories so it does not overwrite the 5k main experiment. The data contains
6{,}000 COCO object-existence pairs and 4{,}000 GQA simple pairs. Its
200-example audit passes the same checks as the main audit: 200/200 chosen
responses correct, 200/200 rejected responses wrong, and 200/200 evidence
hints consistent with the annotations.

Under the normal yes/no prompt, \answerdpo{} reaches 96.5\% / 76.9\% / 94.8\%
accuracy on COCO, GQA, and Hard COCO, respectively. The corresponding
\method{} accuracies are 96.1\% / 76.6\% / 94.4\%. \method{} has lower FPR on
the same three sets (1.6\% vs. 1.8\%, 14.6\% vs. 16.4\%, and 3.8\% vs. 4.8\%),
but lower accuracy and F1. Thus the larger diagnostic set supports the same
paper claim as the 5k main experiment.

\subsection{Reproducibility Notes}

The mixed preference data is exported from a single canonical pair file into
two response formats, which prevents accidental changes in images, questions,
or labels between \answerdpo{} and \method{}. The 200-example audit checks
chosen correctness, rejected wrongness, and evidence-hint consistency. Official
template files are copied from \texttt{cvpr-org/author-kit}; the local
\texttt{local\_xetex\_fonts.tex} shim only fixes Tectonic/XeTeX font encoding
so the official Times/Helvetica families render with proper bold shapes.
