\begin{abstract}
Preference optimization is a practical way to align vision-language models, but
answer-level preference pairs often leave the visual support for a preferred
answer implicit. A model can therefore satisfy the preference objective by
learning answer style or dataset priors rather than by separating supported
from unsupported visual claims. We study a minimal alternative: augmenting both
chosen and rejected responses in Direct Preference Optimization with short,
template-generated evidence hints derived from existing COCO and GQA
annotations. The method keeps the backbone, images, optimizer, DPO loss, and
inference prompt unchanged; only the preference response format changes. On a
5k mixed COCO/GQA preference set with Qwen2.5-VL-7B-Instruct, the resulting
picture is diagnostic rather than uniformly positive. \method{} ties
\answerdpo{} on COCO object existence accuracy (96.1\%) while slightly reducing
false positives (1.8\% to 1.6\%), but it is lower on GQA simple claims
(76.6\% vs. 76.8\%) and Hard COCO (94.6\% vs. 95.0\%). Evidence-style prompting
and a Base-error-mined locked set do not reverse this pattern. A 10k scale-up
diagnostic preserves the same conclusion: \method{} keeps lower false-positive
rates, but \answerdpo{} remains higher on accuracy and F1 across COCO, Hard
COCO, and GQA. These results show that template-level evidence hints can nudge
precision on some unsupported claims, but are not sufficient by themselves to
consistently improve small-scale VLM preference tuning.
\end{abstract}

\section{Introduction}

Modern vision-language models (VLMs) can answer visual questions fluently while
asserting objects, attributes, or relations that are not supported by the
image. This failure mode is especially concerning in simple visual-claim
settings. If a question asks whether a dog is present, whether an object is
red, or whether one object lies to the left of another, the answer should be
checked against visible evidence rather than language priors.

Direct Preference Optimization (DPO)~\cite{dpo} is attractive for VLM alignment
because it optimizes from paired preferences without training a separate reward
model. However, a standard answer-level preference pair usually contains only
the final chosen and rejected responses. The preference signal says which
answer is better, but not why one answer is visually supported. In multimodal
settings this missing ``why'' matters: the model may learn a more preferred
answer template without receiving a textual cue that distinguishes visible from
hallucinated evidence.

We examine whether a small response-format change can make this signal more
grounded. For each preference pair, we keep the same image, question, and
chosen/rejected semantics as an answer-only DPO baseline, but append a compact
evidence hint to both responses. The hint is generated from existing
annotations, such as an annotated visible object, an annotated color attribute,
or an unsupported object claim. We do not add boxes or masks, modify the DPO
loss, change the model architecture, or ask the model to emit evidence at test
time.

The study is intentionally scoped. We ask whether this lightweight signal helps
on controlled visual claims covering COCO object existence and GQA simple
attributes and left/right relations. This scope keeps the main experiment to
three groups--Base Instruct, \answerdpo{}, and \method{}--and lets us isolate
the effect of response format rather than adding new supervision channels.

Our contributions are:
\begin{itemize}
    \item We propose a low-cost preference-data rewrite that injects short
    annotation-derived evidence hints into VLM DPO without changing the model,
    loss, images, or inference prompt.
    \item We construct a 5k aligned COCO/GQA preference set where
    \answerdpo{} and \method{} use the same images, questions, and semantic
    labels, differing only in response format.
    \item We report a controlled diagnostic result: \method{} slightly lowers
    false positives on COCO-style object-existence questions, but does not
    consistently outperform answer-only DPO across GQA, Hard COCO, prompt-mode,
    Base-error-mined evaluations, or a 10k mixed scale-up diagnostic.
\end{itemize}

\section{Related Work}

\paragraph{Hallucination evaluation.}
Object hallucination has been studied in image captioning and VLM evaluation by
checking generated visual claims against annotations or controlled questions.
CHAIR~\cite{chair} measures hallucinated objects in captions, while
POPE~\cite{pope} recasts object hallucination as polling-style object-existence
questions. Our evaluation follows the same diagnostic spirit, but focuses on
how preference-tuning data should represent visual support.

\paragraph{Preference tuning.}
DPO optimizes a policy directly from paired preferences using a frozen
reference model~\cite{dpo}. This simplicity makes it a useful testbed for small
VLM alignment interventions. Unlike methods that add a reward model or a new
training objective, our comparison keeps the objective fixed and changes only
what the chosen and rejected responses contain.

\paragraph{Grounding and evidence supervision.}
Grounded VLM training can use boxes, masks, region phrases, or human-written
rationales to connect language with image regions. Such signals are valuable
but can be costly to collect and integrate. Our evidence hints are deliberately
weaker: they are short templates derived from COCO~\cite{coco} and
GQA~\cite{gqa} annotations. The question is whether even this weak textual
evidence is enough to improve answer-level preference tuning.

\subsection{Answer-Level DPO Baseline}

Let $x=(I,q)$ denote an image-question pair, $y^+$ a preferred response, and
$y^-$ a rejected response. The \answerdpo{} baseline uses ordinary answer
strings, such as a correct yes/no response paired with a hallucinated
alternative. It trains with the standard DPO loss:
\begin{equation}
\mathcal{L}_{\mathrm{DPO}} =
-\log \sigma \left(
\beta \log \frac{\pi_\theta(y^+|x)}{\pi_{\mathrm{ref}}(y^+|x)}
- \beta \log \frac{\pi_\theta(y^-|x)}{\pi_{\mathrm{ref}}(y^-|x)}
\right).
\end{equation}
This baseline receives a preference ordering, but no explicit textual
description of the visual fact that makes the chosen response preferable.

\subsection{Evidence-Hint DPO}

\method{} uses the same $x$, $y^+$, and $y^-$ semantics as \answerdpo{}, but
rewrites the response text by appending a compact evidence hint:
\begin{quote}
\small
\textbf{Question:} Is there a dog in the image?\\
\textbf{Chosen:} Yes, there is a dog in the image. Evidence hint: annotated
visible object: dog.\\
\textbf{Rejected:} Yes, there is a cat in the image. Evidence hint:
unsupported object: cat is not annotated as visible.
\end{quote}
For GQA attributes and relations, the template records the annotated color,
material, or left/right relation that supports the chosen answer, and marks the
conflicting claim in the rejected answer as unsupported. The hint is not a
human rationale or region-level grounding signal. It is only a short textual
cue that exposes the evidence already implicit in the annotation.

This design isolates one variable. \answerdpo{} and \method{} use the same
backbone, training images, questions, chosen/rejected labels, DPO beta, LoRA
rank, and epoch count. Only the response format differs.

\subsection{Preference Data}

The mixed training set contains 5{,}000 aligned preference pairs. COCO
contributes 3{,}500 object-existence pairs. Positive objects come from visible
object annotations; negative objects are sampled from categories not annotated
in the image. GQA contributes 1{,}500 simple attribute and relation pairs from
train scene graphs: 986 color attributes, 64 material attributes, and 450
left/right spatial relations.

The same canonical pairs are exported into two DPO formats. The answer-only
export contains only the final responses, while the evidence-hint export
appends the corresponding support or contradiction template. Held-out
evaluation image ids are excluded from training, yielding zero train/eval image
overlap. A 200-example mixed audit found 200/200 chosen responses correct,
200/200 rejected responses wrong, and 200/200 evidence hints consistent with
the annotations.

We also construct a 10k scale-up diagnostic with the same templates and
held-out exclusions: 6{,}000 COCO object-existence pairs and 4{,}000 GQA simple
pairs. This diagnostic writes separate data, adapters, and evaluation outputs,
and is used only to test whether increasing data size changes the 5k trend.

\section{Experiments}

\subsection{Setup}

We use Qwen2.5-VL-7B-Instruct~\cite{qwen25vl} as the single backbone. Both
trained variants use one epoch of LoRA DPO with $\beta=0.1$ and LoRA rank 16.
The three groups are Base Instruct, \answerdpo{}, and \method{}. No extra
supervised fine-tuning, reward model, region supervision, or prompt-time
evidence requirement is added.

\subsection{Evaluation}

We evaluate on three held-out yes/no sets. The COCO object-existence set
contains 1{,}000 examples balanced between present and absent object claims.
Hard COCO also contains 1{,}000 balanced examples, but uses same-coarse-group
absent objects to increase false-positive pressure. The GQA simple set contains
1{,}000 examples balanced between color-attribute and left/right-relation
questions, and balanced between yes and no labels. All outputs are decoded with
the same yes/no parser. We report accuracy, F1, yes-bias, refusal rate, and
confusion-derived error rates. Refusal covers answers such as ``cannot
determine'' or ``not sure'' that avoid a yes/no decision.

Table~\ref{tab:main} shows a narrow and mixed effect. \answerdpo{} gives small
accuracy gains over the base model on all three held-out sets. \method{} ties
\answerdpo{} on ordinary COCO object existence and slightly reduces the COCO
false-positive rate, but gives up one true positive relative to \answerdpo{}.
The same precision-recall pattern appears on Hard COCO: \method{} lowers FPR
from 4.0\% to 3.8\%, but its FNR rises from 6.0\% to 7.0\%, yielding lower
accuracy. On GQA simple, \method{} also lowers FPR relative to \answerdpo{} but
increases FNR enough that overall accuracy and F1 are lower.

Refusal and invalid-output rates are 0.0\% for all rows. Therefore the
differences are not caused by conservative abstention or parser failures. The
result is better read as a small response-bias shift: template evidence hints
make the model a little less likely to answer ``yes'' to unsupported claims,
but this also removes some correct affirmative answers.

\subsection{Additional Diagnostics}

\paragraph{Evidence-style prompt.}
We also evaluate with an explicit instruction: ``Answer yes or no, then briefly
mention the visual evidence.'' This prompt increases evidence-cue language but
does not make \method{} dominate \answerdpo{}. On COCO, the accuracies are
95.5\% for Base, 95.6\% for \answerdpo{}, and 95.5\% for \method{}. On GQA,
the corresponding accuracies are 76.8\%, 76.6\%, and 76.7\%. Thus explicitly
asking for evidence at inference time is not enough to recover a hidden benefit
from training-time evidence hints.

\paragraph{Base-error-mined set.}
Because ordinary COCO is near ceiling, we mine a locked diagnostic set from
Base Instruct errors on a 10k held-out candidate pool. The candidate pool has
94.72\% Base accuracy and 528 Base errors; after filtering, the locked set has
527 rows: 123 Base false positives and 404 Base false negatives. As shown in
Table~\ref{tab:mined}, both DPO variants recover only a small fraction of these
errors. \answerdpo{} recovers 6.3\% overall, while \method{} recovers 3.0\%.
The only favorable slice for \method{} is false-positive recovery, but it is a
2/123 versus 1/123 difference and should not be over-interpreted.

\paragraph{10k scale-up diagnostic.}
To test whether the mixed result is merely a small-data artifact, we double the
preference set to 10k pairs while keeping the same backbone, DPO objective,
response formats, held-out splits, and normal yes/no evaluation. Table
\ref{tab:scaleup} shows that the scale-up does not change the main claim.
\method{} again lowers false-positive rates, with the largest margin on GQA
simple, but \answerdpo{} remains higher on accuracy and F1 across all three
held-out evaluations.

\section{Limitations}

This study is a controlled, small-scale test rather than a complete solution to
VLM hallucination. The data covers object existence, simple color/material
attributes, and left/right spatial relations; it does not cover counting,
multi-step compositional reasoning, open-ended descriptions, or dense
grounding. Evidence hints are template-generated from existing annotations and
are much weaker than human rationales or region-level supervision. We use one
backbone and one seed; the 10k diagnostic checks scale within the same data
construction rather than exploring broad scaling laws. The results are
therefore best read as a boundary case: the simple hint format tested here is
not sufficient to consistently beat answer-only DPO. Finally, annotation
incompleteness can make some negative object claims ambiguous, and the
Base-error-mined audit is preliminary, so future work should use harder
human-verified negatives, stronger hint designs, and broader benchmarks.

\section{Conclusion}

We presented \method{}, a minimal preference-data rewrite that appends short
annotation-derived evidence hints to chosen and rejected DPO responses while
leaving the model, loss, and inference prompt unchanged. In a controlled
COCO/GQA study, this simple format produces a small reduction in object
false positives, but it does not consistently improve over answer-only DPO on
overall accuracy, GQA simple claims, Hard COCO, evidence-style prompting, or a
Base-error-mined diagnostic set. Doubling the mixed preference data from 5k to
10k preserves this pattern: \method{} lowers FPR but remains below
\answerdpo{} on accuracy and F1. The broader lesson is useful: lightweight
grounding-flavored preference responses are easy to construct and evaluate, but
template hints alone may be too weak to reliably change VLM visual grounding.
