像素证据约束的 VLM 偏好优化

把 VLM/MLLM 的偏好学习从“回答文本更像人类喜欢的答案”推进到“答案中的每个关键断言都能被图像区域、对象关系或 3D/空间证据支撑”。

关键词：VLM alignment 偏好优化 幻觉缓解 细粒度 grounding

一句话选题

提出 Grounded Preference Optimization：训练一个能同时奖励“回答有用性”和“视觉证据一致性”的偏好目标，让 MLLM 在开放式问答、描述、3D 场景理解中减少无证据幻觉。

为什么现在值得做

CVPR 2025 已经出现多篇直接围绕 MLLM 偏好、奖励和幻觉的论文：VisionArena 提供真实用户 VLM 对话偏好；VL-RewardBench 关注视觉语言生成奖励模型；Task Preference Optimization 把任务偏好用于 MLLM 视觉任务对齐；DPO hallucination 工作强调 on-policy 数据；Critic-V 用 VLM critic 捕捉多模态推理错误。

这些 work 说明“视觉后训练”正在进入 CVPR 主流，但大多数偏好信号仍偏文本级、答案级。模型可能学会说得更顺，却没有被强迫说明“哪个像素/对象/关系支持了这个断言”。

前人未完全解决的问题

  • 奖励粒度不够。 现有偏好数据通常比较两个完整回答，难以区分“格式好但看错图”和“表达一般但视觉事实正确”。
  • 视觉证据没有闭环。 reward model 或 critic 常常只读图和文本，不要求输出可验证的区域、对象或关系链。
  • 3D/空间场景更明显。 2D 图像中的对象幻觉已经难，3D 场景理解还涉及方位、遮挡、尺度、可达性，单纯文本偏好更容易失真。

方法草图

模块设计
证据抽取 让模型对关键名词、属性、关系生成 evidence spans：2D box/mask、3D object id、temporal segment 或 scene graph edge。
偏好构造 正样本不仅答案正确，还要证据可定位；负样本覆盖对象替换、属性错配、关系反转、无图像依据的常识补全。
训练目标 组合 DPO/IPO 类偏好损失、grounding consistency loss、answer helpfulness reward。关键是把“看得准”从辅助标注变成优化主目标。
critic 训练一个轻量 visual-evidence critic，对答案断言逐条打分，作为在线数据筛选与自训练门控。

评测路线

  • 开放式 VQA/描述：比较 hallucination rate、object/attribute/relation F1、回答偏好胜率。
  • 细粒度 grounding：用 RefCOCO/Visual Genome/GQA 或自建 object-claim 数据测证据定位一致性。
  • 3D 场景理解：在 ScanQA、3D VQA 或 CVPR 2025 相关 3D VLU benchmark 上测空间关系与对象指代。
  • 奖励泛化：在 VL-RewardBench 上看 reward model 是否偏向漂亮文本而非视觉真实。

最小可行实验

先选一个开源 MLLM，如 LLaVA 系列或 Qwen2.5-VL 系列；用 5k-20k 图像问答对自动构造对象/属性/关系负样本；让 GPT-4o 或强 VLM 生成 evidence labels，再用人工抽样清洗 500 条。第一版只比较 SFT、DPO、Grounded-DPO 三种训练。

投稿卖点

  • 不是又一个偏好数据集，而是把视觉证据纳入偏好优化目标。
  • 能连接 CVPR 近两年的 VLM hallucination、reward benchmark、3D VLU、visual critic 四条线。
  • 如果实验稳定，可以形成清楚的主张：多模态对齐不能只对齐输出文本，还要对齐“回答所依赖的视觉证据”。
