第二稿**进步很明显**，已经从“4 页技术报告”改成了更像一篇 CVPR benchmark / diagnostic paper 的稿子：正文长度达标，Related Work 扩充了，加入了 Figure 1、五组实验、verifier-only control、1k/2k ablation、bootstrap CI、parser audit、BEM 解释和 relation error analysis。
但如果按**真正 CVPR 审稿标准**继续严格看，它仍然是 **Weak Reject / Borderline Reject**，主要卡在：**贡献强度、实验外推性、benchmark 可信度和结果解释深度**。

## 2. 创新性：定位更准确，但贡献仍偏窄

第二稿最大的改进是把 CEPO 的全称补出来了，并且题目改成了：

> Probing Claim-Evidence Consistency in Vision-Language Preference Tuning

这个比第一稿的 “Benchmark for Diagnosing” 更稳，也更符合现在文章的实际贡献。摘要中也明确说 CEPO-Probe 是一个 controlled diagnostic benchmark，而不是泛化的 hallucination benchmark。

这版的核心贡献现在比较清楚：

> answer preference tuning 和 evidence verification 可以朝相反方向变化。

这个发现是有价值的。比如摘要里写到 Answer-DPO 把 wrong-evidence rejection 从 44.3% 降到 34.3%，而 verifier supervision 可以恢复到 53.0% / 70.3%。

但是，创新性仍然有限。

### 主要问题

CEPO-Probe 本身是一个**规则构造的小型诊断集**，不是大规模 benchmark；CEPO-Dual 本身是**混合 answer preference 和 verifier preference**，方法上并不新。文章也承认 ClaimEvidence-6K 是 6,000 training rows，probe 是 600 supported + 400 wrong-evidence，主实验只有五组。

因此它的最佳定位是：

> 一个小而清晰的 diagnostic study。

而不是：

> 一个强 benchmark paper 或强 method paper。

如果真投 CVPR，审稿人可能会问：

1. 这是不是只是把已有 annotation 转成 prompt？
2. 这个 probe 是否太小？
3. CEPO-Dual 是否只是显然地加入了同分布 verifier rows？
4. 结论是否只适用于这一个模型、这一个数据构造和这一个 prompt？

目前文章的回答是“我们只做 bounded conclusion”。这个很诚实，但也会降低主会竞争力。

**严格评分：Novelty 5.5 / 10。比第一稿好，但仍不是强创新。**

## 3. Related Work：明显改进，但仍有“浅列举”问题

第二稿 Related Work 比第一稿强很多，加入了 MME、MMHal-Bench、AMBER、HallusionBench，以及多模态 RLHF / DPO 相关工作。文章也更清楚地说明 CEPO-Probe 与普通 answer-level benchmark 的区别：它问的是 candidate evidence 是否支持 candidate claim。

这是一个好改动。

但 Related Work 仍然偏短、偏综述式，没有充分展开“为什么已有工作不能回答本文问题”。例如 hallucination benchmarks 那段只是说它们看 response-level 或 QA-level behavior，而 CEPO 看 evidence support。这个差异是对的，但还不够深入。

建议继续补强两类比较：

### 需要补的比较 1：与 explanation / rationale evaluation 的区别

文章说 CEPO 不 reward verbose explanations，而是 expose whether model accepts or rejects a specific evidence item。 这很好，但还可以更明确：

* rationale evaluation 评估解释文本质量；
* CEPO-Probe 评估 evidence-label consistency；
* CEPO 不要求生成解释，而是二分类 / 三分类支持判断；
* 因此它更适合作为 preference tuning 的 diagnostic probe。

### 需要补的比较 2：与 grounding benchmark 的区别

现在写到 boxes/masks/rationales 更强但更贵，CEPO 用轻量 annotation-derived labels。 这个说法有风险，因为审稿人可能会理解为：你只是用了更弱的 grounding signal。

建议强调：

> CEPO-Probe is not a replacement for region grounding benchmarks. It targets a different failure mode: whether a model accepts a specified evidence item as support under preference-tuned behavior.

## 4. 数据构造：更清楚了，但可信度仍不够强

第二稿对数据构造的描述比第一稿完整。它明确说明：

* COCO 贡献 object-existence claims；
* GQA 贡献 color/material attributes 和 left/right relations；
* same-answer wrong-evidence rows 让 answer text 不是判别信号；
* probe split 是 600 supported + 400 wrong-evidence；
* 做了 zero train/eval image overlap；
* 做了 200-row annotation-consistency audit。

这些是很好的严谨性补充。

但严格看，还有几个问题。

### 问题 1：200-row audit 太弱

ClaimEvidence-6K 有 6,000 rows，但人工或规则审计只报告了 200-row audit。这个对课程作业够用，但对 benchmark paper 仍然偏少。

尤其是 relation slice 是全文最关键的失败点，而 relation 也是最容易被 annotation noise 影响的部分。审稿人会问：

* 200-row audit 是否按 object / attribute / relation 分层采样？
* relation reversal 的 annotation 是否可靠？
* left/right 是否受图像视角、镜像、物体边界影响？
* GQA scene graph 的 relation 是否本身有噪声？

现在文章没有回答这些。

### 问题 2：probe 和 training distribution 太接近

训练数据和 probe 都来自同一套 COCO / GQA annotation-derived construction。虽然文章检查了 image overlap，但 prompt style、claim template、evidence format 可能高度一致。文章说有 zero train/eval image overlap。 但这只能排除图像重复，不能排除模板分布重复。

审稿人可能会认为 CEPO-Dual-2k 的提升部分来自：

> 学会了 CEPO-Probe 的输出格式和模板规则，而不是更强的视觉 evidence verification。

建议补一个更强的外部 probe：

* unseen template paraphrase probe；
* unseen relation wording probe；
* COCO/GQA 以外的小型手工 probe；
* 或者 human-written evidence phrases。

### 问题 3：same-answer wrong-evidence 的设计需要更多例子

这个是本文最有价值的数据设计，但目前只是描述为 “answer text is intentionally not the discriminating signal”。 建议正文给 2–3 个具体例子。现在 Table 3 有 preference format 示例，但还不够展示 same-answer 的关键性。

## 5. 实验严谨性：比第一稿强很多，但仍缺多模型和多 seed

这是第二稿最大进步点。它新增了：

* Evidence-DPO-only；
* CEPO-Dual-1k；
* CEPO-Dual-2k；
* appendix 里的 CEPO-Dual-500；
* bootstrap CI；
* parser audit；
* BEM 解释。

尤其是 BEM 现在解释清楚了：Base-error-mined recovery 是 base model gets wrong 的集合，所以 base row 为 0 by construction。 这是第一稿的一个明显问题，第二稿修掉了。

### 优点 1：五组实验比第一稿完整

Table 2 现在清楚列出了五组训练设置，包括 answer rows 和 verifier rows。 Table 3 进一步说明了 Answer-DPO、Supported verifier、Wrong-evidence verifier 的 chosen/rejected response。

这让 CEPO-Dual 的训练逻辑更透明。

### 优点 2：结果故事更有说服力

Table 4 和 Table 5 形成了很好的对照：

* Answer-DPO 提升 short-answer，但 wrong-evidence rejection 下降；
* Evidence-DPO-only 提升 wrong-evidence rejection，但不提升 short-answer；
* CEPO-Dual-2k 同时保留 answer gains 和 evidence gains。

这个故事比第一稿完整很多。

### 优点 3：CI 和 parser audit 是实质性增强

Table 6 给了 bootstrap interval，并说明 CEPO-Dual-2k 的 wrong-evidence interval 与 Base 和 Answer-DPO 分开。 这是严谨性上的明显提升。

但仍有几个硬伤。

## 6. 实验硬伤 1：没有 random seeds

文章在 Limitations 里承认只用了 one 7B backbone、one LoRA-DPO recipe、one deterministic decoding setup，并说需要 broader model families 和 random seeds。

这说明作者知道问题，但主文没有解决。

对真正 CVPR 来说，**没有 seed 方差是很大的问题**。尤其是 LoRA-DPO 小数据训练，6k / 2k rows 的结果可能受：

* initialization；
* data order；
* LoRA rank；
* learning rate；
* DPO beta；
* training epoch；
* decoding prompt；

影响。Bootstrap CI 只能说明在固定模型输出上，probe 样本抽样的不确定性；它不能替代训练 seed variance。

必须强调：

> Row-bootstrap CI ≠ training stability.

这点现在文章没有讲清楚。它可能让读者误以为 Table 6 已经证明结果稳定，但其实只是证明固定 run 在 400-row probe 上的估计区间。

建议至少补：

* 3 seeds for Answer-DPO and CEPO-Dual-2k；
* 或者说明课程资源限制下没有跑 seed，但不能在论文语气里暗示训练结论很稳。

## 7. 实验硬伤 2：只有一个 backbone

全篇只用 Qwen2.5-VL-7B-Instruct。 这对课程项目可以接受，但对 benchmark paper 不够。

因为本文的主张是：

> answer preference and evidence verification can move independently.

这个主张看起来是 general phenomenon，但实验只在一个模型上验证。严格来说，当前只能说：

> On Qwen2.5-VL-7B-Instruct under this LoRA-DPO recipe, answer preference and evidence verification separate.

摘要里虽然写了 “Under a fixed Qwen2.5-VL-7B backbone”，比较克制。 但 Discussion 的表达有些泛化，比如 “Answer and evidence skills separate”。 这句话最好改成：

> In our controlled Qwen2.5-VL setting, answer and evidence behaviors separate.

否则审稿人会认为 overclaim。

## 8. 实验硬伤 3：CEPO-Dual-2k 的 1k→2k 跳变太大，需要解释

Table 5 显示：

* CEPO-Dual-1k Wrong Rej. = 48.5
* CEPO-Dual-2k Wrong Rej. = 70.3

这个提升非常大。 Appendix Table 10 也显示：

* Dual-500 = 39.5
* Dual-1k = 48.5
* Dual-2k = 70.3。

这当然是好结果，但也可疑。为什么 1k 到 2k 会有这么大的非线性跃迁？可能原因包括：

1. 2k verifier rows 包含更多 wrong-evidence rows；
2. 2k 覆盖了更多 object/attribute 模板；
3. 1k sampling 不均衡；
4. 2k 训练步数更多，等于训练量更多；
5. DPO mixture 中 answer/verifier ratio 改变；
6. 可能有过拟合到 probe style。

现在文章只说 “verifier data scale matters”。 但这不够。

建议补充：

* 1k 和 2k verifier rows 的类别分布；
* verifier rows 中 supported / wrong-evidence 比例；
* object / attribute / relation 的比例；
* 训练 step 是否随数据量增加；
* 是否控制总训练 rows 数，例如固定 8k rows，用不同 mixture ratio。

否则 CEPO-Dual-2k 的提升可能被认为是“更多训练数据”的效果，而不是“verifier preference”的效果。

## 9. 指标与 parser：修得更好了，但 100% Strict JSON 仍然值得怀疑

第二稿把第一稿的 Invalid JSON 改成了 Strict JSON、Scored Output、Parse Fail，这是正确改动。它也说明 strict JSON 是 raw output parseable JSON，scored-output 还包括 deterministic fallback。

但是 Table 5 / Table 6 里所有模型 Strict JSON 都是 100.0，Parse Fail 都是 0.0。

这不一定错，但仍然需要解释：

* 是否 prompt 中强制输出 JSON？
* 是否使用 constrained decoding？
* Base Instruct 为什么也能 100% strict JSON？
* 是否只统计 evidence probe，不统计 short-answer？
* strict JSON 是否真的严格，例如单引号、尾随文字、markdown code block 是否算失败？

如果没有 constrained decoding，Base Instruct 100% strict JSON 在 1000-row probe 上有点过于完美。建议在 appendix 给 parser audit 的定义和样本输出，否则审稿人会怀疑 metric 被 parser 设计“洗干净”了。

## 10. Relation failure 分析：有进步，但还可以更尖锐

第二稿新增了 slice and error analysis，这是非常好的改动。文章指出 CEPO-Dual-2k 在 object 和 attribute 上提升明显，但 relation wrong-evidence rejection 只有 25.6%，并且给了 slice bootstrap interval。

这部分是全文最有价值的分析之一。

但问题是：relation failure 现在还是被描述成“textual left/right labels alone are not enough”。这个解释是合理的，但还可以更深入。

你应该追问学生：

### relation reversal 的低分到底说明什么？

有两种可能：

1. 模型真的不懂空间关系；
2. CEPO-Probe 的 relation evidence format 本身不充分。

如果是后者，那么 relation slice 不能完全证明模型 grounding 差，而是证明当前 textual relation probe 不够强。

文章在 Discussion 中说当前 textual evidence representation 不要求模型 identify regions，因此如果两个 objects 都存在，模型会接受 swapped relation。 这点很好，但可以进一步变成一个明确的威胁：

> The relation failure may reflect both model weakness and benchmark underspecification.

这会让论文更严谨。

## 11. 外部实验：只能算 sanity check，不能支撑主张

第二稿把 POPE / AMBER 定位成 external sanity checks，而不是主要 claim。这个处理是正确的。文章明确说 CEPO-Dual-2k 与 Answer-DPO 的外部差异很小，所以不把它作为 primary claim。

但从严格审稿角度看，这也说明：

> CEPO-Probe 的提升目前主要是 internal benchmark 提升。

也就是说，CEPO-Dual-2k 在 CEPO-Probe 上提升很大，但没有明显带来外部 hallucination benchmark 的提升。这个并不致命，因为论文定位是 diagnostic benchmark。但它会削弱“实际价值”。

建议学生在 Discussion 里更明确说：

> The evidence probe is not meant to predict POPE/AMBER performance. It measures a different consistency behavior.

否则读者会问：既然外部指标没变，这个训练方法有什么意义？

## 12. 写作：更成熟，但还有一些“自我防御过多”的问题

第二稿语气明显更成熟，尤其是多次强调 bounded conclusion：

* “diagnostic rather than a broad hallucination-benchmark win”；
* “intentionally small”；
* “does not claim solved hallucination”；
* “not a broad external benchmark breakthrough”。

这比过度宣称好。比如摘要最后就把 claim 限制得很清楚。

但严格说，现在有一点**防御性太强**。全文反复强调 small、compact、bounded、not broad，这会让审稿人觉得作者自己也认为贡献偏小。

建议保留克制，但减少过度自我削弱。比如：

原风格：

> The study is intentionally small.

可以改成：

> We focus on a controlled setting to isolate the effect of verifier preferences.

这样更积极。

## 14. 模拟审稿意见

### Strengths

1. The paper identifies a meaningful diagnostic gap: answer-level preference tuning may not improve evidence-level verification.
2. The revised version includes stronger controls than the first draft: verifier-only, mixed 1k/2k settings, bootstrap intervals, parser audit, and slice analysis.
3. The main empirical pattern is clear and interesting: Answer-DPO improves short-answer behavior but reduces wrong-evidence rejection, while CEPO-Dual-2k recovers wrong-evidence rejection.
4. The paper is appropriately cautious and does not overclaim broad hallucination improvements.

### Weaknesses

1. The empirical scope is narrow: one backbone, one LoRA-DPO setup, one decoding setup, and no training seed variance.
2. The benchmark is small and mostly annotation/template-derived, raising concerns about whether CEPO-Dual learns general evidence verification or benchmark-specific output behavior.
3. The large jump from CEPO-Dual-1k to CEPO-Dual-2k is underexplained.
4. Relation verification remains very weak, and it is unclear whether this reflects model limitation or insufficient evidence representation.
5. External benchmark gains are negligible, so the practical relevance of the verifier training remains limited.
6. The Related Work and data construction sections still do not fully establish why existing grounding, rationale, or hallucination benchmarks cannot answer the same question.

### Questions for the authors

1. How stable are the results across random seeds?
2. Does the effect hold for another VLM backbone?
3. What happens under paraphrased CEPO-Probe prompts?
4. Are the 1k and 2k verifier rows category-balanced?
5. Does CEPO-Dual-2k still improve if the total number of training rows is controlled?
6. Why is strict JSON validity 100% for all models?
7. How much of the relation failure comes from poor spatial reasoning versus ambiguous textual relation evidence?

## 16. 下一版最应该改什么

最优先不是继续润色语言，而是补**能真正提高可信度的实验**：

1. **至少 3 seeds**：Answer-DPO、Evidence-DPO-only、Dual-2k 三组即可。
2. **一个额外 backbone**：哪怕是更小的 VLM，也比没有强。
3. **paraphrased probe**：改写 prompt 和 evidence 表达，测试是否只是学模板。
4. **控制总训练 row 数**：证明 Dual-2k 不是单纯因为训练数据更多。
5. **解释 1k→2k 跳变**：给 verifier row 分布和 per-slice 增长曲线。
6. **parser audit 附录细化**：解释为什么 strict JSON 是 100%。

一句话评价第二稿：

> 第二稿已经是一篇结构完整、主张克制、实验链条清楚的课程论文；但如果按 CVPR 主会标准，它仍然缺少跨模型、跨 seed 和跨模板验证，因此目前的贡献更像一个有价值的 controlled diagnostic study，而不是一个足够强的 benchmark / method paper。
