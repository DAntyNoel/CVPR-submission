课程要求正文 6/7/8 页，而这篇稿件目前正文从 Abstract 到 Conclusion，参考文献已经在第 4 页开始，附录从第 5 页开始。也就是说，**正文实际不足 6 页**，不满足课程要求。论文结论结束在 line 271，随后就是 References；附录从 line 296 开始。

建议优先补到 **6 页正文**，不要只是拉长文字，而是补充：

1. 更完整的 Related Work；
2. 更详细的数据构造流程图或伪代码；
3. 更清楚的 DPO / CEPO-Dual 训练样本格式；
4. 更多实验分析：置信区间、错误案例、relation failure 分析、ablation。

当前摘要和贡献写得比较清楚：论文提出 CEPO-Probe，用于检查 claim-evidence consistency，并强调短答案正确不等于视觉证据正确。这个核心动机是成立的。

## 2. 创新性审阅

### 优点

这篇稿子的核心创新点是：**把 VLM preference tuning 的评价从 answer-level accuracy 拆到 claim-evidence consistency**。这个问题意识是好的。文章明确指出，模型可能答对 yes/no，但引用或接受了错误证据，例如把 “sink visible” 的证据写成 “potted plant”。

贡献列表也比较聚焦：提出 CEPO-Probe，构造 ClaimEvidence-6K，并设计固定的 supported / wrong-evidence probe。 这对于一篇 benchmark / diagnostic paper 来说，是比较合理的组织方式。

### 主要问题

**创新性目前偏“诊断集 + 小实验”，还不足以支撑强 CVPR 论文。**

CEPO-Dual 本身不是特别新的方法，它本质上是把 answer preference 和 evidence-verifier preference 混合训练。文章也写到 CEPO-Dual 使用相同的 6,000 answer rows 加 2,000 verifier rows。 这个设计合理，但作为“方法创新”比较弱。

因此，建议不要把论文包装成一个强方法论文，而是明确定位为：

> A diagnostic benchmark and controlled study showing that answer preference tuning and evidence consistency are separable.

也就是：**创新点不是 CEPO-Dual 多强，而是 CEPO-Probe 能揭示 answer-DPO 掩盖的问题。**

### 需要增强的创新表达

现在 benchmark 的独特性还没有和已有工作拉开。Related Work 只有 object hallucination、preference tuning、grounding/rationales 三小段，而且引用只有 6 篇。 对 CVPR 投稿来说明显太少。

建议补充比较：

| 方向                                             | 需要说明 CEPO-Probe 的差异                                                      |
| ---------------------------------------------- | ------------------------------------------------------------------------ |
| POPE / CHAIR / AMBER 类 hallucination benchmark | 它们多看 object hallucination 或 yes/no answer，CEPO 看 claim 与指定 evidence 是否一致 |
| Grounding benchmark                            | CEPO 不要求 boxes/masks，而是轻量 label/relation evidence                        |
| Rationale / explanation evaluation             | CEPO 不评价自由文本 explanation quality，而评价 candidate evidence support decision |
| VLM preference tuning                          | 现有 DPO 多优化 answer preference，CEPO-Probe 检查 evidence-level side effect    |

一句话：**你需要证明这不是“又一个 hallucination benchmark”，而是专门诊断 preference tuning 后 answer correctness 与 evidence correctness 分离的 benchmark。**

## 3. 严谨性审阅

### 做得好的地方

数据部分有一些很好的严谨性设计。比如 ClaimEvidence-6K 明确来自 COCO 和 GQA，覆盖 object、attribute、relation 和 same-answer wrong evidence 四类样本。 文章还报告了 zero train/eval image overlap，以及 200-row annotation-consistency audit，说明作者有意识地控制数据质量。

实验结果也没有过度宣称“解决 grounding”，而是指出 relation reversal 仍然很差。CEPO-Dual 的 wrong object 和 wrong attribute rejection 很高，但 wrong relation 只有 25.6%。 这一点是诚实的，也增强了论文可信度。

### 关键问题 1：实验规模太小

主实验只有一个 backbone：Qwen2.5-VL-7B-Instruct。模型组也只有 Base、Answer-DPO 和 CEPO-Dual 三个。 作为课程作业可以接受，但如果模拟 CVPR 投稿，审稿人会质疑：

* 是否只对 Qwen2.5-VL 有效？
* 是否对不同模型尺寸有效？
* 是否对不同 preference tuning recipe 有效？
* 是否有随机种子波动？
* LoRA-DPO 一轮训练是否稳定？

你在 Limitations 里承认了“one 7B backbone and one small-data LoRA-DPO recipe”，但这只是承认问题，还没有解决问题。

最低建议补充：

1. 至少 3 个 random seeds，报告均值和标准差；
2. 至少一个额外 backbone，例如 LLaVA / InternVL / Qwen2-VL 小模型；
3. CEPO-Dual verifier rows 数量 ablation：500 / 1k / 2k；
4. answer-only vs evidence-only vs answer+evidence。

### 关键问题 2：probe 太小，需要置信区间

supported-evidence probe 只有 600 rows，wrong-evidence probe 只有 400 rows。 400 条样本上报告 70.2% vs 34.3% 是有说服力的，但每个 slice 更小，比如 relation wrong 只有 125 条。此时 25.6% 的数值需要置信区间，否则读者不知道差异是否稳定。

建议在 Table 3 加：

* 95% confidence interval；
* bootstrap standard error；
* 或者至少写明每个 slice 的样本数。

比如：

| Slice     |   N | CEPO-Dual rejection | 95% CI |
| --------- | --: | ------------------: | -----: |
| Object    | 126 |                96.0 |    ... |
| Attribute | 149 |                85.9 |    ... |
| Relation  | 125 |                25.6 |    ... |

### 关键问题 3：BEM 指标不清楚

Table 2 里 BEM 一列显示 Base Instruct 是 0.0，Answer-DPO 是 18.0，CEPO-Dual 是 19.4。 但正文没有解释 BEM 的构造、指标含义和数值方向。读者会疑惑：

* BEM 是 Base-error-mined set 吗？
* 0.0 是 accuracy 还是 improvement？
* 为什么 Base 是 0.0？
* 18.0 / 19.4 是百分点提升，还是准确率？

这个地方必须补清楚，否则 Table 2 的可信度会下降。

### 关键问题 4：Invalid JSON 全是 0.0 有点可疑

Table 3 中所有模型 Invalid JSON 都是 0.0。 这不是不可能，但需要解释：

* 是否使用了强约束 decoding？
* prompt 是否强制 JSON？
* parser 是否有 fallback？
* fallback 后还算 valid JSON 吗？

附录里写到 evidence-probe scorer 会先 parse JSON，然后 fallback to labeled fields。 那么 Table 3 的 “Invalid JSON” 名字可能不准确，因为如果 fallback 成功，它其实不是真正的 JSON valid rate。建议改成：

* `Unparseable Rate`
* `Invalid / Unparsed`
* 或者分别报告 `Strict JSON Valid` 和 `Scored Output Rate`

### 关键问题 5：CEPO-Dual 的训练样本构造需要更透明

现在只说 CEPO-Dual 加了 2,000 evidence-verifier preference rows。 但读者不知道：

* verifier chosen / rejected 长什么样？
* answer preference 和 evidence preference 的 prompt 是否相同？
* evidence-verifier rows 是否来自同一 6K？
* train 和 probe 是否共享 image、claim template、evidence label？
* wrong-evidence rows 是否可能和 evaluation distribution 太接近？

建议加一个小表：

| Training type | Input                               | Chosen                | Rejected               |
| ------------- | ----------------------------------- | --------------------- | ---------------------- |
| Answer-DPO    | image + question                    | yes/no correct answer | wrong yes/no answer    |
| Evidence-DPO  | image + question + claim + evidence | JSON support judgment | wrong support judgment |

并给一个完整例子。

## 4. 结果解释是否充分

目前结果故事是成立的：

* Answer-DPO 提高 COCO / Hard COCO 短答案准确率；
* 但 GQA FPR 上升，说明 yes bias 增强；
* Answer-DPO 的 wrong-evidence rejection 从 Base 的 44.3% 掉到 34.3%；
* CEPO-Dual 把 wrong-evidence rejection 提到 70.2%。

这个故事很清楚，也是全文最强的部分。

但是目前解释还不够深入。特别是 relation reversal 为什么失败？文章只是说 remain hard at 25.6%。 建议补一个专门小节：

### Why relation reversals remain hard?

可以分析：

1. VLM 对 left/right 本来就弱；
2. relation evidence 是 textual label，不提供 region-level grounding；
3. object 和 attribute 可以靠局部识别，relation 需要比较两个实体的位置；
4. 训练中的 evidence-verifier preference 可能没有强迫模型定位 subject/object；
5. candidate evidence swaps subject/object，模型可能只看到两个 object 都存在，就误判 supported。

这会让论文从“报结果”变成“解释现象”，更像 CVPR 论文。

## 5. 措辞与写作审阅

整体英语比较干净，语气也相对克制。优点是没有过度吹 CEPO-Dual，Limitations 写得诚实。比如 Introduction 里明确说 “Our goal is not to claim that a new preference-tuning method solves visual hallucination”，这个措辞很好。

但也有几个问题。

### 问题 1：标题里的 CEPO 没有解释

标题是：

> CEPO-Probe: A Claim-Evidence Consistency Benchmark for Diagnosing Vision-Language Preference Tuning

但正文没有解释 CEPO 是什么缩写。建议第一次出现时写：

> Claim-Evidence Preference Optimization Probe (CEPO-Probe)

或者如果 CEPO 不是缩写，就不要用这个名字。CVPR 审稿人会对不解释的 acronym 比较敏感。

### 问题 2：Abstract 信息密度高，但方法贡献不够突出

摘要目前结果很清楚，但 benchmark 构造流程略抽象。建议在摘要里加一句：

> CEPO-Probe converts annotation-derived objects, attributes, and relations into controlled candidate-claim/candidate-evidence pairs, allowing same-answer wrong-evidence cases.

这样读者马上知道 benchmark 是怎么来的。

### 问题 3：“compact diagnostic benchmark” 容易显得贡献小

你多次说 compact / small / diagnostic。这个很诚实，但也会削弱论文气势。可以保留 diagnostic，但不要过度强调 small。

比如：

原句：

> We introduce CEPO-Probe, a small benchmark designed to isolate this question.

建议：

> We introduce CEPO-Probe, a controlled diagnostic benchmark designed to isolate this question.

“controlled diagnostic” 比 “small” 更像论文贡献。

### 问题 4：Related Work 太像占位符

Related Work 只有三段，每段都很短。现在给人的感觉是“知道有这些方向，但没有真正比较”。建议每个方向至少写 1 段完整讨论，并明确 CEPO-Probe 的差异。尤其是 grounding and rationales 那段，现在只说 boxes/masks/rationales costly，然后说 CEPO uses weaker labels。 这个说法容易被攻击为“你的监督更弱，所以 benchmark 也更弱”。

建议改成：

> CEPO-Probe is not intended to replace region-grounded evaluation. Instead, it targets a complementary failure mode: whether a model accepts a specific candidate evidence item as support for a claim, even when no dense region annotations are available.

这样能避免被审稿人理解成“弱监督替代强 grounding”。

## 8. 最核心的修改方向

这篇稿子最应该强化的不是“把 CEPO-Dual 写得更厉害”，而是把论文主张收紧成：

> Preference tuning can improve answer-level behavior while degrading evidence-level verification. CEPO-Probe provides a controlled way to reveal this hidden failure mode.

这个主张很清楚，也比“我们提出一个新方法提升 grounding”更可信。建议全文围绕这个中心改写。
